# SEO & Apps — Highest Degree Priorities

**Live domain:** https://seoandapps.com/  
**Repository:** grandopenauto/seoandapps  
**Purpose:** A distinct, light, polished marketing front door into HDP's search, app, and connected operating systems capabilities.

## Positioning
**Get found. Get chosen. Get things done.**

- SEO: improve discoverability with useful pages, local listings, technical fundamentals and meaningful measurement.
- Apps: make the post-click experience practical; web apps, portals and mobile-responsive sites, with native-app feasibility evaluated separately.
- Connected systems: connect defined user actions to governed follow-through and measured operating outcomes.
- Other front doors: HDPJoin (education), SISOBS (vision), HDP BOS (operating layer).

This site does not claim guaranteed rankings, traffic, sales, app-store approval, or fully autonomous operations.

## Architecture
Pure static HTML/CSS and small vanilla JavaScript, GitHub Pages main/root, no runtime dependencies, no secrets, and no backend. Original SVG favicon and social graphic. The interactive business opportunity finder is client-side and collects nothing. The primary contact path is an email draft. Separate substantive editorial service pages support legitimate search needs, rather than duplicated keyword doorway content.

## Publishing notes
Preserve the exact existing root `CNAME` file, `seoandapps.com`. GitHub Pages should deploy from main / root; verify DNS and enforced HTTPS. Check all site routes and assets return 200, mobile menu and finder operate, CTA email works, metadata and canonicals are correct, and downstream HDP pages open. Submit `https://seoandapps.com/sitemap.xml` to Google Search Console when the site is stable. UTMs alone do not constitute conversion tracking.

## Future iteration
Connect analytics through HDP's approved collector with privacy review. Integrate a protected inquiry/CRM backend only after server-side validation, anti-spam, consent, secure storage and explicit authorization. Do not put bridge tokens, service ports, or internal BOS registries into this public repository.
